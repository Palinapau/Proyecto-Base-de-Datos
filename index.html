Base de Datos KOAJ San Pedro

Proyecto desarrollado por Paulina Díaz Perdomo y William Collo Narváez

Descripción del Proyecto

La base de datos KOAJ San Pedro fue diseñada para gestionar la información de una tienda de ropa incluyendo productos, categorías, tallas, colores, stock por tienda, clientes, ventas, empleados, seguridad y control de accesos. Este sistema permite administrar el inventario, registrar ventas, manejar usuarios con permisos y realizar consultas avanzadas sobre productos.

Tablas Principales

  • Categorías: Almacena los tipos de productos.
  • Tallas: Lista de tallas disponibles.
  • Colores: Paleta de colores manejados por los productos.
  • Proveedores: Información de proveedores externos.
  • Productos: Catálogo de ítems disponibles en las tiendas.
  • Sucursales: Información de cada tienda KOAJ.
  • Stock_Tienda: Registro del inventario por producto, talla y color en cada sucursal.
  • Empleados: Datos del personal de las tiendas.
  • Clientes: Información de clientes.
  • Ventas: Registra cada venta realizada.
  • DetalleVenta: Productos incluidos en cada venta.

Tablas de Seguridad

El proyecto incluye un sistema básico de roles y permisos con las siguientes tablas:

  • Seg_Usuarios: Usuarios del sistema.
  • Seg_Roles: Roles del sistema.
  • Seg_Permisos: Permisos otorgados.
  • Seg_UsuarioRol: Relación usuario–rol.
  • Seg_RolPermiso: Relación rol–permiso.
  • Seg_Sesiones: Registro de sesiones.
  • Seg_LogEventos: Logs de actividades.
  • Seg_IntentosFallidos: Seguridad contra intentos fallidos.
